Every thumbs up/down submitted on an assistant response, across all of Chat — filter to **All**,
**Positive**, or **Negative** at the top. Each row shows the rating, the message it was left on (as
a short id, not a link), an optional comment the person left alongside the rating, and when it was
submitted.

This is the raw list behind [Analytics](/docs/analytics)' feedback trend chart and top-failing-queries
table — useful when you want to read the actual comments, not just the counts.

Shows an empty state until someone has rated a response.
