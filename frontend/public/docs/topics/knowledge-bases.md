A Knowledge Base is a named collection of documents that retrieval is scoped around — the
boundary chat and search draw from. Most workspaces only need one ("Company Knowledge Base" or
similar), but splitting into more than one is useful when you want, say, engineering docs and HR
policies to never answer each other's questions.

To create one: **Knowledge Bases → New knowledge base**, give it a name and an optional
description, and save. [Knowledge Sources](/docs/knowledge-sources) and uploaded
[Documents](/docs/documents) are then assigned to a knowledge base, either when you connect/upload
them or afterward. Each knowledge base's card shows its document count, embedding model, a
**public** badge when it's shared beyond its owning tenant, and the documents currently assigned to
it. **Delete** only works on an empty knowledge base — move or remove its documents first.
